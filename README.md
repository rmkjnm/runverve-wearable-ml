# Runverve — Wearable Fatigue Prediction Prototype

AI/ML Engineer Intern submission.

A supervised Random Forest prototype predicting Low, Moderate, or High fatigue from synthetic wearable-style physiological, sleep, activity, and hydration-proxy signals.

## Run locally

```bash
python3 -m pip install -r requirements.txt
jupyter notebook
```

Open `Runverve_Fatigue_Prediction.ipynb` and run all cells.

## Important

The dataset is synthetic. The model is a technical demonstration and is not clinically validated.
